# JobStack 🚀

The curated discovery directory and stack for freelancers, job seekers, and remote professionals to find their next client or opportunity.

## Features

- **Curated Directory**: Platforms, job boards, cold outreach systems, AI assistants, and portfolio tools.
- **Dedicated Directory Page**: Streamlined filtering by category, real-time live search, and list/grid views.
- **Tool Inspection**: Interactive detail modal with sequential navigation (`←` / `→`).
- **Dark Mode Design System**: Built with CSS variables, gradients, and responsive layouts.

## Tech Stack

- **React 19**
- **TypeScript**
- **Vite**
- **Vanilla CSS Modules / Design Tokens**

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
